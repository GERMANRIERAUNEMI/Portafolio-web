Sobre mí

Me interesa el desarrollo web de principio a fin: desde la base de datos hasta la pantalla que usa la gente.

Soy desarrollador web. Empecé con HTML y CSS, y hoy trabajo con JavaScript en el navegador y con Python y Django en el servidor.

Me gusta aprender construyendo. Cada proyecto me obliga a resolver algo nuevo: sincronizar jugadores en tiempo real, diseñar una base de datos para historias clínicas o usar inteligencia artificial para analizar imágenes médicas.

Busco prácticas o proyectos donde pueda aportar en desarrollo web y seguir creciendo en backend y bases de datos.
